快速上手Getting Started

从下载安装到手柄跑起来，大约需要五分钟。 From download to a working controller in about five minutes.

下载与安装Download & Install

  1. 在 CurseForge 项目页的 Files 中选择与你的 MC 版本、加载器一致的 JAR。 On the CurseForge project page, pick the file matching your MC version and loader.
  2. 把 JAR 放入游戏的 mods/ 文件夹（Fabric 版请确认已安装 Fabric API）。 Put the JAR into the game's mods/ folder (on Fabric, make sure Fabric API is installed too).
  3. 启动游戏。控制器的连接状态、名称与类型可在 Control Flex 设置 → 手柄选择（Gamepad Selection）中查看。 Launch the game. Connection status, name, and type of each controller appear under Control Flex Settings → Gamepad Selection.

多手柄（热插拔）：Control Flex 通过 SDL3 热插拔事件自动识别手柄，按手柄身份（名称 / 类型 / 序列号）分别记忆配置；当前手柄断开后会自动切换到下一个可用手柄。 Multiple controllers (hotplug): Control Flex detects pads via SDL3 hotplug events and tracks them by identity (name / type / serial). If the active pad disconnects, the first available one is selected automatically.

打开设置Opening Settings

默认按键：键盘 F9，手柄 Back + Start。这个按键本身也是一个可改绑的动作，位置在按键映射的 Control Flex 分类里。 Defaults: F9 on keyboard, Back + Start on a controller. The open-settings action is itself rebindable and lives in the Control Flex category of Key Mapping.

选择模板Pick a Template

首次启动会内置三个模板，可在设置中随时切换： Three templates ship with the mod; switch between them in the settings screen at any time:

模板Template定位What it is
Basic基础映射：A 跳跃、RT 攻击、LT 使用、左摇杆移动、右摇杆视角The foundation: A jump, RT attack, LT use, left stick move, right stick look
Bedrock贴近基岩版手柄布局的手感Closer to the Bedrock Edition controller feel
Recommend作者推荐的整合包向布局，预置更多常用动作The author's modpack-oriented layout with more actions pre-bound

模板就是一套默认键位；你自己的修改会单独保存，不污染模板。详见设置与键位。 A template is a set of default bindings; your edits are stored separately and never modify the template. See Settings & Controls.

Overlay 层（交互式 HUD 打开时）layer (interactive HUDs)

Overlay 层是显式绑定、不继承 Main：默认保留移动、跳跃、攻击、使用、视角与滚动，B 为返回。未配置的动作在 Overlay 相位中保持静默，避免误触发战斗键位。 The Overlay layer is explicit (no Main inheritance): movement, jump, attack, use, look, and scrolling stay bound, with B as back. Unconfigured actions stay silent during overlays so combat keys cannot misfire.

虚拟键鼠与阈值Virtual KBM & Thresholds

  • 虚拟键鼠：B 在界面中注入物理 Esc；LT 注入左 Shift（GUI 层）；Page Up / Page Down 已配置为 GUI 层可用。Virtual KBM: B injects physical Esc in screens; LT injects Left Shift (GUI layer); Page Up / Page Down are enabled for the GUI layer.
  • 阈值默认值：Tap 500 ms，Long Press 1000 ms（可在“其他设置”中调整）。Default thresholds: Tap 500 ms, Long Press 1000 ms (configurable in Other Settings).

以上是 Basic 模板的默认值。Bedrock 与 Recommend 模板略有差异，所有键位都可以在设置里改绑 —— 改键方法与校准请看设置与键位。 These are the Basic template defaults. Bedrock and Recommend differ slightly, and every binding can be changed — see Settings & Controls for rebinding and calibration.
