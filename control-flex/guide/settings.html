设置与键位Settings & Controls

设置界面用 F9（键盘）或 Back + Start（手柄）打开。这一页讲清楚：界面里有什么、怎么改键、怎么校准、配置存在哪、出问题先看什么。 Open settings with F9 (keyboard) or Back + Start (controller). This page covers what is in the UI, how to rebind, how to calibrate, where configs live, and what to check when something misbehaves.

设置界面一览Inside the Settings Screen

区域Area 用途What you do there

改键方法Rebinding

  1. 在按键映射里找到目标动作所在的层与分类（可以用搜索框直接搜动作名或拼音）。Find the action's layer and category in Key Mapping (search by name, or by Chinese pinyin).
  2. 点选该行进入捕获状态，然后按下手柄按键 —— 界面会实时显示解析结果。Select the row to start capture, then press a controller button — the resolved input appears live.
  3. 需要和弦时：先按第一颗键，在 500 ms 内继续追加，直到和弦完整。For a chord: press the first button, then add the rest within 500 ms until the chord is complete.
  4. 部分动作有推荐模式（例如层切换固定为 Hold、Shift 层返回 Main 固定为 Release），界面会限制为可用模式。Some actions restrict their mode (layer switches are fixed to Hold; Shift-layer return-to-Main to Release) and the UI only offers valid modes.

被修改过的项会标记为“用户修改（User modified）”，与模板默认值区分开；可以按页重置，也可以整体恢复模板默认。 Edited entries are marked “User modified”, keeping them distinct from template defaults; reset per page or restore the whole template default.

摇杆与扳机校准Stick & Trigger Calibration

  • 死区按轴独立配置：左摇杆 X/Y、右摇杆 X/Y、左扳机、右扳机。Deadzones are per-axis: left stick X/Y, right stick X/Y, left trigger, right trigger.
  • 支持一键自动校准（全部轴）与单项校准（只针对某个轴），校准时实时显示轴数值，便于确认摇杆是否漂移。Both one-click auto calibration (all axes) and single-axis calibration are available, with live axis readouts so you can spot drift.
  • 移动与视角的响应曲线也在这页调整；模拟移动策略（360° / 键盘式 8 向）在“其他设置”里。Movement and camera response curves live here too; the Analog Movement policy (360° / keyboard-like 8-way) is under Other Settings.

模板、配置档案与重置Templates, Profiles & Reset

  • 模板（Basic / Bedrock / Recommend）是一套完整的默认键位；自定义模板可以作为 JSON 放入 config/controlflex/templates/。Templates (Basic / Bedrock / Recommend) are complete default layouts; custom templates can be dropped in as JSON under config/controlflex/templates/.
  • 你的修改保存在配置档案（profiles）里，与模板分离 —— 切换模板不会丢失，也不会改写模板文件。Your edits live in profiles, separate from the template — switching templates neither loses them nor rewrites the template file.
  • 支持按页重置和整体重置到模板默认。Reset per page, or restore everything to template defaults.
  • 从 0.8.6.x 升级时，配置档案、兼容文件与客户端设置会在首次启动时自动迁移，原文件备份在 config/controlflex/backup/ 下。Upgrading from 0.8.6.x migrates profiles, compat files, and client settings automatically on first launch; originals are backed up under config/controlflex/backup/.

按键检测（调试）Key Detection (Debug)

排查“为什么这个键没反应”时，可以打开逐 tick 的检测日志面板：它会显示物理按键、虚拟按键、解析出的动作、所在层与时间信息，并提供游戏内 / GUI 两种测试模式以匹配不同输入路径。面板激活期间，手柄输入专用于记录。 To debug “why did that button do nothing”, open the tick-by-tick detection log. It shows physical keys, virtual keys, the resolved action, the layer, and timing, with separate In-Game and GUI test modes matching the different input paths. While active, controller input is dedicated to logging.

配置文件位置Where Configs Live

config/controlflex/
├── templates/      # 模板 JSON# template JSON files
├── profiles/       # 你的修改（配置档案）# your edits (profiles)
├── compat/         # 模组兼容配置（default / mods / user）# mod compat configs (default / mods / user)
├── radial_menu/    # 径向菜单布局与图标# radial menu layouts and icons
├── backup/         # 升级迁移时的自动备份# automatic backups from migrations
└── cfx-client.json # 客户端状态# client state

整合包作者关心的分层与覆盖规则在配置文件页。 Layer priority and override rules for pack authors are on the Configuration page.

常见问题Troubleshooting

手柄完全没反应Controller not detected

先在“手柄选择”里确认是否识别到设备（名称 / 类型）。若列表为空：换一个 USB 口或重新配对蓝牙、确认系统里手柄可用、确认 JAR 与 MC 版本 / 加载器匹配；Fabric 环境请确认 Fabric API 已安装。 First check Gamepad Selection for a detected device (name / type). If the list is empty: try another USB port or re-pair Bluetooth, verify the pad works system-wide, and make sure the JAR matches your MC version and loader; on Fabric, confirm Fabric API is installed.

某个模组的按键绑了却没反应A mod's key is bound but does nothing

按顺序检查：① 这个界面属于哪一层（Screen / Overlay / Main），绑到正确的层；② 在“模组适配”里为该模组的界面添加规则或同步社区配置；③ 若模组只监听物理键，用虚拟键鼠绑定。完整排查流程见模组兼容性。 Check in order: (1) which layer the screen belongs to (Screen / Overlay / Main) and bind there; (2) add a rule for that mod's screen in Mod Adaptation, or sync a community config; (3) if the mod only listens to physical keys, bind it via Virtual KBM. Full flow on Mod Compatibility.

服务器上移动看起来“不正常”Movement looks abnormal to a server

把模拟移动策略切换为“键盘式 8 向”（公共服务器与 Realms 的默认值）；确需平滑移动时把该服务器加入白名单。见功能详解的模拟移动一节。 Switch the Analog Movement policy to keyboard-like 8-way (the default for public servers and Realms); whitelist a server if it should still get smooth movement. See the Analog Movement section of Features.

切到别的窗口后角色不动了Character freezes when the window loses focus

这是原版的“失去焦点时暂停”。按 F3+P 关闭（分屏双人必须关闭，暂停界面也会有提示）。 That is vanilla Pause on Lost Focus. Press F3+P to disable it (required for couch co-op; the pause screen also shows a hint).

想彻底重来一遍Starting over from scratch

可以先把 config/controlflex/ 整个目录备份改名，再让游戏重新生成默认配置；社区配置与模组内的内置配置会在下次启动时重新释放。 Back up and rename the whole config/controlflex/ directory; the game regenerates defaults on the next launch, and community/packaged configs are re-extracted at startup.
