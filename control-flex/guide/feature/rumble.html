功能详解Features

震动反馈Rumble

把 Minecraft 的事件翻译成手柄震动：7 种波形，按事件类型分别配置，再配一组轻 / 中 / 重的强度阈值 —— 挨打和击杀的手感可以完全不同。 Minecraft events translated into controller vibration: seven waveforms, configured per event type, with light / medium / heavy intensity bands — taking a hit and scoring a kill can feel completely different.

7 种波形Seven Waveforms

波形Waveform 手感Feel
关闭None该类型不震动No vibration for that type
脉冲Pulse短促的一下，适合轻伤害A short jolt, good for light hits
双脉冲Double Pulse两连击的手感Two quick pulses
渐强Crescendo由弱渐强的推进感Ramps up from light to strong
长震Sustained持续震动，适合爆炸等大事件Continuous buzz for big events like explosions
渐弱Fade由强渐弱，收尾感Strong then fading out
心跳Heartbeat两下轻一重的节律，适合低血量 / 紧张场景A lub-dub rhythm, good for tension or low-health moments

按事件类型配置Configured per Event Type

  • 伤害类型：摔落、火焰、溺水、生物、玩家、爆炸、其他 —— 每类单独选波形（含“关闭”）。Damage types: fall, fire, drown, mob, player, explosion, other — each picks its own waveform (including “none”).
  • 击杀事件：击杀实体也可以有自己的反馈。Entity kills: kills can have their own feedback.
  • 强度分级：全局的轻 / 中 / 重伤害阈值，让同一种伤害按轻重给出不同强度。Intensity bands: global light / medium / heavy thresholds, so the same damage type can hit differently depending on severity.
  • 总开关：不想震的时候一键关闭全部反馈。Master switch: turn everything off in one place.

怎么调Tuning It

  1. 打开 Control Flex 设置 → 震动，先确认当前手柄被识别为支持震动（不支持震动的手柄该页无效果）。Open Control Flex Settings → Rumble and confirm the current pad reports rumble support (pads without it simply do nothing here).
  2. 用页面上的强度档位测试逐档试听轻 / 中 / 重的手感，再决定阈值。Use the built-in intensity tests to feel light / medium / heavy, then set thresholds.
  3. 按事件类型挑波形：摔落之类的小事件用脉冲，爆炸用长震，被玩家击杀可以留给“玩家伤害”单独配置。Pick waveforms per type: a pulse for falls, a sustained buzz for explosions, and a distinct feel for player damage.

联机时自己的震动只受自己的设置影响；多人战斗里的反馈事件（打出伤害 / 被谁打）由游戏事件驱动，因此在服务器与单机中的表现一致。 In multiplayer your rumble follows your own settings; the events that drive it come from the game itself, so singleplayer and server play behave the same.
