功能详解Features

光标与界面操作Cursor & GUI

打开背包或箱子后，手柄要能像鼠标一样指、点、拖。Control Flex 的 Screen 层用三套机制覆盖这件事：虚拟光标、格子吸附与 D-Pad 跳格。 Once a chest or inventory is open, a pad has to point, click, and drag like a mouse. The Screen layer covers this with three mechanisms: a virtual cursor, slot snapping, and D-Pad slot jumps.

虚拟光标Virtual Cursor

  • 驱动方式：使用左摇杆的原始轴值，经 Minecraft 的鼠标事件管线移动光标 —— 与方向绑定（cursor_navi_*）是两套独立机制。How it moves: the left stick's raw axis values are routed through Minecraft's mouse event pipeline — a separate mechanism from the direction bindings (cursor_navi_*).
  • 光标速度：2–20 像素 / tick，在光标设置中调节。Cursor speed: 2–20 pixels per tick, tuned in Cursor Settings.
  • 光标样式：系统光标、基岩版样式或手型样式（随光标样式包提供纹理）。Cursor style: the system cursor, a Bedrock-style set, or a hand style (textures ship with the cursor style packs).

格子吸附Slot Snapping

  • 默认开启，可在光标设置中关闭。On by default, switchable in Cursor Settings.
  • 摇杆停止时，光标吸附到最近的容器格；吸附距离 1–80 像素可调。When the stick stops, the cursor snaps to the nearest container slot; the snap distance is adjustable from 1–80 pixels.
  • 仅在手持物品时生效 —— 空手移动光标时不会“粘住”，定位更自由。Only active while holding an item — an empty hand moves the cursor freely without sticking.
  • 悬停减速：启用吸附后，光标悬停在格子上会减速，便于精确选取。Hover slowdown: with snapping on, the cursor slows while hovering a slot for precise selection.

D-Pad 槽位跳转D-Pad Slot Navigation

不需要精确移动光标时，用 D-Pad 在格子之间直接跳转：采用扇形 / 锥形瞄靶，横向长条与不规则格网（如自定义容器）也能可靠跳格。跳格与虚拟光标并存 —— 左摇杆随时可以接管自由移动。 When precision is not needed, the D-Pad jumps between slots directly. It uses cone-shaped targeting, so long horizontal rows and irregular grids (custom containers) still jump reliably. Slot jumps coexist with the virtual cursor — the left stick takes over free movement at any time.

延伸：只认物理键的界面Beyond: Screens That Only Read Physical Keys

有些模组界面不理会虚拟光标，只响应键盘 / 鼠标事件 —— 这时用虚拟键鼠注入真实按键（例如把 B 映射为物理 Esc）。为特定界面定制摇杆行为（独立方向 / 轮盘路径 / 虚拟鼠标）则在模组适配的界面规则里设置。 Some mod screens ignore the virtual cursor and only react to keyboard/mouse events — use Virtual Keyboard & Mouse to inject real keys there (e.g. map B to physical Esc). To customize stick behavior per screen (Independent / Radial Path / Virtual Mouse), add a Screen rule in Mod Adaptation.
