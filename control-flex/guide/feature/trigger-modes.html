功能详解Features

触发模式Trigger Modes

每个绑定由“哪个键”和“怎么触发”两部分组成。Control Flex 提供 10 种触发模式，同一颗按键可以同时承担轻按、长按、按住、切换与双击行为。 Every binding pairs which button with how it fires. Control Flex offers ten trigger modes, so one button can tap, hold, latch, and double-press for different actions.

十种模式The Ten Modes

模式Mode 触发时机When it fires 典型用途Typical use
Press按下瞬间触发一次Once, on button down一次性动作、开关类操作One-shots and menu opens
Release松开瞬间触发一次Once, on button upShift 层返回 Main、“松手生效”的动作Layer return, “on let go” actions
Hold按住期间持续激活Active the whole time held移动 / 视角、持续使用、层切换键Movement, look, sustained use, layer switches
Tap短于 Tap 阈值的按下并松开时触发一次；按住超过阈值则松开时不触发Once, on release after a short press; if held past the threshold, nothing fires on release不误触发长按的快速动作Quick actions that must not fire on a hold
Long Press按住超过 Long Press 阈值后触发一次Once, after being held past the long-press threshold同一按键的第二功能（如暂停菜单）A second function on the same button (e.g. pause menu)
Toggle第一次按下激活并保持，第二次按下释放；与按键是否按住无关（RELEASE 事件被忽略）First press activates and holds, second press releases; independent of button hold (RELEASE events are ignored)疾跑、走路模式、视角等持续状态Persistent states: sprint, walk mode, POV

Double Tap两次短按，在第二次松开时触发一次Two short presses; fires once on the second release不抢占第一次点击的确认类动作Confirm-style actions that must not steal the first tap
Double Hold先短按，再在 Tap 窗口内按住；按住期间保持激活Short press, then press-and-hold inside the tap window; stays active until release“轻点再接长按”才触发，防误触Tap-then-hold for deliberate triggers that resist misfires

阈值与时间窗口Thresholds & Time Windows

  • Tap 与 Long Press 阈值：全局设置，范围 100–2000 ms，位置在其他设置。它们同时作用于所有绑定与模板。Tap and Long Press thresholds are global, 100–2000 ms, configured in Other Settings. They apply to every binding and template.
  • Tap 阈值也是所有双击模式的间隔上限：连按、连点、连按住、连点切换都用它作为两次按键之间的最大间隔。The Tap threshold doubles as the gap limit for every Double mode: Double Press / Tap / Hold / Toggle all use it as the maximum interval between the two presses.
  • 默认值：Tap 500 ms、Long Press 1000 ms（来自 Basic 模板）。Defaults: Tap 500 ms, Long Press 1000 ms (from the Basic template).

怎么改模式Changing a Mode

  • 在按键映射里，模式列可以循环切换常用模式（Press / Hold / Tap / Long Press）。In Key Mapping, the Mode column cycles through the common modes (Press / Hold / Tap / Long Press).
  • 模板与 compat JSON 支持全部 10 种，写法为 button|MODE，例如 buttonA|HOLD、rightStickClick|DOUBLE_TOGGLE；模式 token 为 PRESS / RELEASE / HOLD / TAP / LONG_PRESS / TOGGLE / DOUBLE_PRESS / DOUBLE_TAP / DOUBLE_HOLD / DOUBLE_TOGGLE。Templates and compat JSON support all ten, written as button|MODE — for example buttonA|HOLD or rightStickClick|DOUBLE_TOGGLE. Mode tokens: PRESS / RELEASE / HOLD / TAP / LONG_PRESS / TOGGLE / DOUBLE_PRESS / DOUBLE_TAP / DOUBLE_HOLD / DOUBLE_TOGGLE.
  • 部分动作限定模式：层切换键固定 HOLD，Shift 层返回 Main 固定 RELEASE，径向菜单的打开绑定支持 PRESS 与 HOLD。Some actions restrict their mode: layer switches are fixed to HOLD, Shift-layer return-to-Main to RELEASE, and radial-menu opens support PRESS and HOLD.
