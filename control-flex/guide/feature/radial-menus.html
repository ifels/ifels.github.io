功能详解Features

径向菜单Radial Menus

最多 5 个独立轮盘，每个环绕摇杆至多 8 个槽位：打开轮盘、用摇杆瞄准、按 A 确认。食物、火把、/home 这类高频但不值得占用面键的操作，都适合放进轮盘。 Up to five independent wheels, each with as many as eight slots around the stick: open a wheel, aim with the stick, confirm with A. Food, torches, /home — frequent actions that do not deserve a dedicated face button belong on a wheel.

打开与选择Opening & Selecting

  • 打开方式跟随菜单绑定：Press 为轻按打开（松手不关闭，再点确认或返回），Hold 为按住保持打开、松开关闭。Opening follows the menu's binding: Press taps to open (release does not close it), Hold keeps it open while held and closes on release.
  • 选择摇杆：左摇杆、右摇杆或双摇杆（默认双摇杆）。Selection stick: left, right, or both (both by default).
  • 菜单与层绑定：每个菜单有一个所属层。默认布局是：菜单 1 在 Main，菜单 2–5 分别在 Shift 1–4 —— 所以 Shift 层除了扩展按键，也是轮盘的入口层。Menus are assigned to layers: by default Menu 1 lives on Main and Menus 2–5 on Shift 1–4 — Shift layers serve as wheel entry points as well as binding planes.

图标与外观Icons & Appearance

  • 图标模式：自动（按槽位内容推断，如物品图标）、随机、默认、物品 ID、或自定义纹理路径。Icon modes: auto (inferred from the slot's content, e.g. item icons), random, default, item ID, or a custom texture path.
  • 游戏内编辑器可以调整图标、槽位顺序，以及每个菜单自己的触发方式。The in-game editor lets you pick icons, reorder slots, and set the trigger mode per menu.

配置文件Config Files

轮盘布局保存在 config/controlflex/radial_menu/radial_menus.json，图标资源放在同目录下。整合包可以把这个文件随包分发，让玩家开箱即用；文件结构（节选）： Wheel layouts persist in config/controlflex/radial_menu/radial_menus.json with icons alongside. Packs can ship this file so players start with working wheels. Structure (excerpt): 

{
  "version": 1,
  "selectionStick": "BOTH",
  "menus": [
    { "id": 1, "name": "Menu 1", "mode": "HOLD",  "assignedLayer": "main",   "slots": [ 8 × slot ] },
    { "id": 2, "name": "Menu 2", "mode": "HOLD",  "assignedLayer": "shift1", "slots": [ … ] },
    { "id": 5, "name": "Menu 5", "mode": "PRESS", "assignedLayer": "shift4", "slots": [ … ] }
  ]
}

所有槽位出厂时都是空的 —— 轮盘是一个容器，内容由你（或整合包作者）填充。同一颗 Back 因为分属不同层，可以分别打开 5 个不同的轮盘。 All slots ship empty — a wheel is a container you (or a pack author) fill. The same Back button opens five different wheels because each menu belongs to a different layer.
