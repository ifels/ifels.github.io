功能详解Features

分屏双人（同机合作）Split-Screen Co-op

Java 版不在同一个窗口里渲染两名玩家，所以“同机双人”的形态是：同一台电脑上开两个客户端，通过“对局域网开放”联机，各自用自己的手柄。Control Flex 为这个用法做了两处专门支持：手柄归属与失焦窗口继续运行。 Java Edition does not render two players in one window, so couch co-op means two clients on one PC joined over Open to LAN, each with its own controller. Control Flex supports that setup in two specific ways: controller ownership and unfocused windows that keep playing.

你需要准备What You Need

  • 两个以上的 Minecraft 账号。Two or more Minecraft accounts.
  • 两把手柄，或者一把手柄 + 一套键鼠。Two gamepads, or one gamepad plus keyboard and mouse.
  • 一个能同时开两个实例的启动器。A launcher that can run two instances at once.
  • 每一个“用手柄”的实例都安装 Control Flex。Control Flex installed in each instance that uses a gamepad.
  • 可选：Splitscreen Support（只做窗口平铺，不处理输入）。Optional: Splitscreen Support (window tiling only, no input handling).

步骤Steps

  1. 为每个账号各建一个启动器实例，两边都保持窗口模式（不要全屏）。Create one launcher instance per account; keep both windowed (not fullscreen).
  2. 安装模组：手柄实例装 Control Flex（可选再装 Splitscreen Support）。Install the mods: Control Flex in the gamepad instances, optionally Splitscreen Support too.
  3. 启动两个客户端。双柄场景：在两边的 手柄选择里分别指定不同的手柄；手柄 + 键鼠场景：只给那个手柄实例指定手柄，另一位用键鼠。Launch both. Two pads: pick a different controller in each game's Gamepad Selection. Pad + keyboard: assign the pad in the gamepad instance only.
  4. 每个窗口按 F3+P 关闭“失去焦点时暂停”（或在视频设置里改）—— 后台窗口必须继续运行；暂停界面也会有提示。Press F3+P in each window to disable Pause on Lost Focus (or change it in video options) — the unfocused window must keep running; the pause screen also shows a hint.
  5. 装了 Splitscreen Support 的话，按 F11 循环半屏 / 四分之一屏布局，它会记住上次的位置。With Splitscreen Support, press F11 to cycle half- and quarter-screen layouts; the last position is remembered.
  6. 在其中一个实例上对局域网开放，其他实例从多人游戏列表里加入，或用 localhost + 开放时的端口连接。Host on one instance (Open to LAN); join from the others from the multiplayer list, or via localhost plus the port shown.

视角模式的选择Picking a Look Mode

  • 后台窗口用 Direct Turn 或 Smooth Turn。Use Direct Turn or Smooth Turn in background windows.
  • Simulate Mouse 无法驱动后台窗口的系统光标，会自动回退到 Direct Turn —— 想避开这种切换就统一用 Direct / Smooth。Simulate Mouse cannot drive the OS cursor in a background window and falls back to Direct Turn automatically — use Direct or Smooth everywhere to avoid the switch.

手柄“抢输入”是多手柄场景最常见的问题：SDL3 会如实报告设备，但两个客户端各自选了同一把。只要在手柄选择里分配不同的设备即可；手柄断开时 Control Flex 会自动切到第一把可用手柄，所以尽量使用各自固定的那一把。 “Input stealing” is the classic two-pad problem: SDL3 reports devices honestly, but both clients might pick the same one. Just assign different devices in Gamepad Selection. When a pad disconnects, Control Flex auto-selects the first available one, so keep each player on their own device.
