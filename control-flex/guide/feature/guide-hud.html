功能详解Features

游戏内指南In-Game Guide

不用切出去查文档：Control Flex 把按键提示做进了游戏里 —— 情境 HUD 会按当前动作、手持物品、打开的界面或手柄按键显示对应提示，指南列表则汇总所有可用指南。 No need to alt-tab to a document: Control Flex brings the reference into the game. Context HUD tips appear for the current action, held item, open screen, or controller button, and the guide list gathers everything available.

情境 HUD 提示Context HUD Tips

指南条目可以标记为 HUD 显示：这类提示会根据情境出现在屏幕上 —— 例如进入世界时的移动 / 交互基础提示、手持特定物品时该物品的操作提示、打开某个界面时该界面的按键提示。条目针对的“动作”直接使用 Control Flex 的动作体系，因此你改过的键位会如实反映在提示里。 Guide entries can be marked for HUD display: those tips appear on screen in context — the movement and interaction basics when you first join, tips for a specific held item, or the key hints for a screen you just opened. Entries reference Control Flex actions directly, so your own rebinds are reflected in the tips.

指南列表The Guide List

  • 按 Guide 键打开指南列表（open_guide 动作，Basic 模板默认绑在 Guide），界面里可用 LB / RB 切换标签。Press the Guide button to open the list (open_guide, bound to Guide in the Basic template); LB / RB switch tabs inside.
  • 列表按分类组织，指南带有触发条件（例如“首次进入世界”）与若干条目，条目由“动作 + 标签 + 显示方式”组成。The list is organized by category; each guide has a trigger (such as “first join”) plus entries made of an action, a label, and a display mode.

按钮图标随平台变化Button Glyphs Follow the Platform

提示里的按钮图标按当前手柄类型切换（Xbox / PlayStation / Switch 布局各有映射，任天堂布局还会处理 A/B 互换），因此同一句提示在 DualSense 与 Xbox 手柄上显示的图标都是对的。 Glyphs in the tips follow the connected controller: Xbox, PlayStation, and Switch layouts each have their own mappings, and the Nintendo layout handles the A/B swap — so the same tip shows the right icons on a DualSense and an Xbox pad alike.

配置文件Config Files

指南 JSON 位于 config/controlflex/guides/（分层：default/ 内置、mods/ 桥接模组安装、user/ 你的修改）；首次运行会把内置默认复制出来。结构（节选）： Guide JSON lives in config/controlflex/guides/ (layered: default/ packaged, mods/ installed by bridge mods, user/ your edits); the packaged defaults are copied out on first run. Structure (excerpt): 

{
  "mod_id": "controlflex",
  "categories": [
    {
      "id": "basic",
      "guides": [
        {
          "id": "movement",
          "title": "controlflex.guide.basic.movement",
          "trigger": { "type": "first_join" },
          "entries": [
            { "action": "move_forward", "label": "controlflex.guide.entry.move", "display": "auto_move", "hud": true },
            { "action": "jump",         "label": "controlflex.guide.entry.jump",  "hud": true }
          ]
        }
      ]
    }
  ]
}

什么时候用得上When It Helps

  • 整合包作者：把“这包怎么玩手柄”做成指南文件随包分发，新玩家进世界就看到该按什么。Pack authors: ship a guide describing your pack's controller layout so new players see it the moment they join.
  • 桥接模组：可以在安装 compat 配置的同时安装 guide 资源（见 onInstallGuideAssets，插件与示例），给模组的关键操作加提示。Bridge mods: install guide assets alongside compat configs (onInstallGuideAssets, see Plugin & Examples) to add tips for key actions.

相关：设置与键位（按键检测面板，排查提示为何不出现）、API 参考（reloadGuides() 与 IControllerCapabilities）。 Related: Settings & Controls (the key-detection panel for debugging missing tips) and the API Reference (reloadGuides() and IControllerCapabilities).
