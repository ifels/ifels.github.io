功能详解Features

模拟移动（360°）Analog Movement (360°)

原版 Minecraft 只把 WASD 当作开关，所以“摇杆转按键”只能八方向全速行走。开启模拟移动后，Control Flex 直接提供连续的 360° 移动向量：任意角度，轻推即慢走。 Vanilla Minecraft only sees WASD as on/off, so stick-to-keys walking is limited to eight directions at full speed. With Analog Movement, Control Flex feeds a continuous 360° vector: any angle, and a light push walks slowly.

两种策略Two Policies

策略Policy 行为Behavior 适合Best for
Analog Smooth 方向与推杆幅度原样使用 —— 主机式手感Direction and magnitude used as-is — the console feel 单机、局域网、允许平滑移动的服务器Singleplayer, LAN, and servers that tolerate smooth movement
键盘式 8 向Keyboard-like 8-way 摇杆吸附到八个方向、全速行走，在服务器看来与键盘输入一致Stick snapped to eight directions at full speed, which looks like keyboard input to a server 公共服务器与 RealmsPublic servers and Realms

默认怎么选How the Default Is Chosen

默认策略随连接场景自动变化： The default follows the connection:

  • 单机 / 局域网 → Analog SmoothSingleplayer / LAN → Analog Smooth
  • 公共服务器与 Realms → 键盘式 8 向，避免“摇杆幅度”被服务端反作弊视为异常输入Public servers and Realms → keyboard-like 8-way, so analog walk is less likely to look like abnormal input to server-side anti-cheat

在哪里设置Where to Configure

  • Control Flex 设置 → 其他 → 模拟移动：总开关 + 策略选择。Control Flex Settings → Other → Analog Movement: master switch plus policy.
  • 服务器白名单：确需在某个远程服务器使用 Analog Smooth 时，在同一页把它加入白名单（host:port 或 Realm 名称）。Server whitelist: if a specific remote server should still get Analog Smooth, add it (host:port or Realm name) on the same page.
  • 关闭总开关后回到数字 WASD 绑定；策略选项随之失效。Turning the master switch off restores digital WASD bindings; the policy then does nothing.

与校准的关系Relation to Calibration

移动手感的另外两个旋钮在校准页：摇杆死区（每根摇杆一个值，按手柄分别保存）与移动响应曲线。死区没调好时，轻推可能不动或漂移 —— 先跑一次自动校准，再微调死区，最后再调响应曲线。 Two more knobs live on the Calibration page: stick deadzones (one value per stick, saved per controller) and the movement response curve. If a light push does nothing or drifts, run auto calibration first, then fine-tune the deadzone, and only then adjust the response curve.

在服务器上“看起来像键盘”只影响移动向量的形态，不影响你按下的任何动作键 —— 战斗、交互等绑定照常工作。 Looking keyboard-like on a server only changes the shape of the movement vector; every action key you press behaves exactly the same.

相关：相机与瞄准（视角的响应曲线同样在校准页）、设置与键位（校准操作步骤）。 Related: Camera & Aim (the look curve also lives under Calibration) and Settings & Controls (calibration steps).
