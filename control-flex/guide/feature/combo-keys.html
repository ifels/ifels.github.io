功能详解Features

组合键Combo Keys

一颗按键不够时，按下多颗：把 LB + Back 或 LT + A 这样的和弦绑定到一个动作。低频但重要的动作不必占用面键。 When one button is not enough, press several: bind a chord such as LB + Back or LT + A to a single action. Rare-but-important actions no longer need a dedicated face button.

怎么捕获一个和弦Capturing a Chord

  1. 在按键映射里点选目标行，进入捕获状态。Select the target row in Key Mapping to start capture.
  2. 先按第一颗键，然后在 500 ms 内追加其余按键；界面上会显示已捕获的完整和弦。Press the first button, then add the rest within 500 ms; the UI shows the full chord as it builds.
  3. 和弦完成后，所有按键同时按下才会触发该动作 —— 单独按其中一颗仍然执行它原本的绑定。Once complete, all buttons must be down together for the action to fire — pressing one of them alone still performs its own binding.
  4. 按 ESC 取消捕获；右键行可以清除、重置或改层。ESC cancels capture; right-click a row to clear, reset, or move it to another layer.

捕获窗口固定为 500 ms，不随 Tap 阈值变化。 The capture window is fixed at 500 ms; it does not follow the Tap threshold.

组合键引擎的三条规则Three Engine Rules

  • 升级规则：较大的和弦激活时（如 A+B+Y），已经激活的、按键集合是它真子集的较小和弦（A+B）会被销毁。这让组合行为保持可预测。Upgrade rule: when a larger chord activates (say A+B+Y), any active smaller chord whose buttons are a proper subset of it (A+B) is destroyed. Behavior stays predictable.
  • 按键共享（引用计数）：一颗物理按键可以同时参与多个和弦，引擎按引用计数管理，互不干扰。Button sharing (reference counting): one physical button can take part in several chords; the engine tracks references so they do not interfere.
  • 支持全部触发模式：和弦可以使用与单键相同的 10 种模式，包括各种双击变体。Every trigger mode works: chords support the same ten modes as single-key bindings, including all the Double variants.

注意事项Things to Watch

  • 和弦的前提是“所有键同时处于按下状态”；如果一颗键被常用的 Hold 绑定长期占用（例如 LT 的“使用”），和弦里带上它会更容易误触，慎重选择。A chord requires every button to be held at once; if one of them is heavily used as a Hold binding (say LT for “use”), including it makes accidental chords more likely — choose deliberately.
  • 和弦同样受全局 Tap / Long Press 阈值影响（双击类模式以 Tap 阈值作为两次间隔）。Chords respect the global Tap / Long Press thresholds too (Double modes use the Tap threshold as their gap).
  • 模板 JSON 中和弦写作按键名用 + 连接："drop_stack": "rightStickClick+dpadDown|PRESS"。In template JSON a chord joins button names with +: "drop_stack": "rightStickClick+dpadDown|PRESS".
