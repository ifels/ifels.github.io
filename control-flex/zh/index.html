Control Flex

面向整合包的灵活手柄映射模组 —— 把一个手柄，变成整包的操作台。

Minecraft 1.7.10 – 26.3 Forge / NeoForge / Fabric Windows · macOS · Linux · Android 仅客户端 MIT
前往下载（CurseForge） GitHub Discord

Control Flex 的名字取自 Control + Flex：通过 7 层按键架构、10 种触发模式、组合键、径向菜单和跨层映射，把有限的按键变成对模组内容的广泛覆盖。它的模组适配系统可以自动发现模组按键、按界面（Screen / Overlay）定制摇杆行为，并支持社区配置库与桥接模组 API。

功能亮点

7 层按键架构

Main / Shift 1–4 / Screen / Overlay，每个场景各自一套键位；Shift 层完全显式，移动与视角默认沿用 Main。

查看详解 →

10 种触发模式

Press、Release、Hold、Tap、Long Press、Toggle 及四种双击变体，一个按键多种行为。

查看详解 →

组合键

多键和弦触发一个动作，带优先级升级规则，适合把低频动作收进和弦。

查看详解 →

径向菜单

5 个轮盘 × 8 个槽位，可绑定按键、命令或快捷使用物品。

共 13 个 MC 版本；Fabric 版需要 Fabric API，SDL3 已内置（Android 上由启动器提供，无需单独安装）。逐版本依赖见 MC 版本支持，桌面与 Android 启动器的差异见 平台支持。

三步上手

  1. 在 CurseForge 下载对应 MC 版本与加载器的 JAR，放进 mods/ 文件夹。
  2. 启动游戏，连接手柄 —— Control Flex 通过 SDL3 自动识别（支持热插拔）。
  3. 按 F9（键盘）或 Back + Start（手柄）打开设置，选择模板并开始调整。
