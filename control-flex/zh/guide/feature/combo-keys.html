功能详解

组合键

一颗按键不够时，按下多颗：把 LB + Back 或 LT + A 这样的和弦绑定到一个动作。低频但重要的动作不必占用面键。

怎么捕获一个和弦

  1. 在按键映射里点选目标行，进入捕获状态。
  2. 先按第一颗键，然后在 500 ms 内追加其余按键；界面上会显示已捕获的完整和弦。
  3. 和弦完成后，所有按键同时按下才会触发该动作 —— 单独按其中一颗仍然执行它原本的绑定。
  4. 按 ESC 取消捕获；右键行可以清除、重置或改层。

捕获窗口固定为 500 ms，不随 Tap 阈值变化。

组合键引擎的三条规则

  • 升级规则：较大的和弦激活时（如 A+B+Y），已经激活的、按键集合是它真子集的较小和弦（A+B）会被销毁。这让组合行为保持可预测。
  • 按键共享（引用计数）：一颗物理按键可以同时参与多个和弦，引擎按引用计数管理，互不干扰。
  • 支持全部触发模式：和弦可以使用与单键相同的 10 种模式，包括各种双击变体。

三种常见用法

模式 例子 说明
给常用键加“第二功能” Basic 模板：右摇杆按下 + D-Pad ↓ = 丢弃整组 “丢弃”已有单个绑定，整组丢弃很少用，收进和弦
触发器的第二功能 RT + D-Pad ← / → = JEI 查看配方 / 用途 攻击键上加方向，成对记忆，也不挤占 GUI 之外的键位
Shift + 和弦 先按住层切换键，再在该层上按和弦 在不占用 Main 层槽位的前提下继续扩展布局

注意事项

  • 和弦的前提是“所有键同时处于按下状态”；如果一颗键被常用的 Hold 绑定长期占用（例如 LT 的“使用”），和弦里带上它会更容易误触，慎重选择。
  • 和弦同样受全局 Tap / Long Press 阈值影响（双击类模式以 Tap 阈值作为两次间隔）。
  • 模板 JSON 中和弦写作按键名用 + 连接："drop_stack": "rightStickClick+dpadDown|PRESS"。
