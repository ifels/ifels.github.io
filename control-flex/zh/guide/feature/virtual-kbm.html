功能详解

虚拟键鼠

有些模组从不注册 KeyMapping —— 它们只监听物理键盘或鼠标。虚拟键鼠让手柄直接向游戏注入真实的按键事件（Shift、Escape、Page Up/Down、鼠标按键、滚轮），无需先把它变成 Control Flex 动作。

怎么用

  1. 在按键映射里找到虚拟键鼠区域，点“添加”，先按下一个键盘 / 鼠标按键作为目标（例如 Escape 或滚轮）。
  2. 然后在任意层上给这个键绑定手柄组合（可以是单键，也可以是和弦）并启用该层。
  3. 虚拟键鼠条目按层分别启用：同一个物理键可以只在 Main 层生效、或只在 GUI 层生效 —— 默认这套配置就是按层写的（见下面的默认表）。

特殊行为

  • 滚轮：轻按滚动一格；按住则连续滚动，默认每 100 ms 一格（可配置）。
  • GUI 返回即物理 Esc：界面里的 B 发送真实的 Esc，效果与鼠标点击 Esc 完全一致 —— 这让拒绝手柄输入的模组界面也能正常退出。
  • 不污染聊天栏：注入的按键不会输入到聊天或文本框中。

注意：注入的按键可能与已有的动作绑定同时触发（例如同一个 LT 既有 Control Flex 动作、又注入了左 Shift）。配置时留意重叠，必要时把两者分配到不同层。

默认值（Basic 模板）

物理键 生效层 说明
Escape 界面（随 GUI 返回键） 让只认 Esc 的界面可以退出
Left Shift Main · Overlay · GUI GUI 层绑定在 LT（快捷移动 / 快速堆叠）
Page Up / Page Down 界面 翻页类模组界面

什么时候该用它

按这个顺序判断：① 模组键已注册在 KeyMapping 里 → 直接用（自动发现）；② 界面 / 摇杆行为不对 → 去模组适配加规则；③ 只监听物理键 → 虚拟键鼠；④ 模组完全绕开 KeyMapping（自定义输入系统）→ 需要桥接模组（见开发者文档）。
