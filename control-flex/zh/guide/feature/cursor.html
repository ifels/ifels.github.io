功能详解

光标与界面操作

打开背包或箱子后，手柄要能像鼠标一样指、点、拖。Control Flex 的 Screen 层用三套机制覆盖这件事：虚拟光标、格子吸附与 D-Pad 跳格。

虚拟光标

  • 驱动方式：使用左摇杆的原始轴值，经 Minecraft 的鼠标事件管线移动光标 —— 与方向绑定（cursor_navi_*）是两套独立机制。
  • 光标速度：2–20 像素 / tick，在光标设置中调节。
  • 光标样式：系统光标、基岩版样式或手型样式（随光标样式包提供纹理）。

格子吸附

  • 默认开启，可在光标设置中关闭。
  • 摇杆停止时，光标吸附到最近的容器格；吸附距离 1–80 像素可调。
  • 仅在手持物品时生效 —— 空手移动光标时不会“粘住”，定位更自由。
  • 悬停减速：启用吸附后，光标悬停在格子上会减速，便于精确选取。

D-Pad 槽位跳转

不需要精确移动光标时，用 D-Pad 在格子之间直接跳转：采用扇形 / 锥形瞄靶，横向长条与不规则格网（如自定义容器）也能可靠跳格。跳格与虚拟光标并存 —— 左摇杆随时可以接管自由移动。

四档光标速度（需要 Control Flex 0.9+）

光标速度不再只有一个固定值，而是沿摇杆死区归一化后的偏移量分四档 —— 慢 / 中 / 快 / 全速。全速档在 95% 偏转时进入、92% 时退出，摇杆老化也不必非顶到 1.0。

  • 卡片式设置：光标设置重做成相机风格的卡片 —— 每档一行、标注各自的摇杆偏移区间，相邻行互相钳制、不会级联。
  • 可调分档点：档位之间的分界可以自己调。
  • 配置迁移：旧配置继续用固定速度模式，全新安装默认启用四档。

延伸：只认物理键的界面

有些模组界面不理会虚拟光标，只响应键盘 / 鼠标事件 —— 这时用虚拟键鼠注入真实按键（例如把 B 映射为物理 Esc）。为特定界面定制摇杆行为（独立方向 / 轮盘路径 / 虚拟鼠标）则在模组适配的界面规则里设置。
