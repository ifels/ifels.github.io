功能详解

径向菜单

最多五个独立转盘，每个沿摇杆一周最多 12 个槽位：打开转盘、摇杆瞄准、A 键确认。食物、火把、/home —— 不值得单独占一个脸键的高频操作，都放进转盘。

槽位能做什么

类型 作用 示例
按键绑定 触发原版或模组的 KeyMapping 切换视角、模组技能键
聊天指令 执行以 / 开头的命令 /home · /spawn · /warp
使用物品 切换到对应的快捷栏格并直接使用 火把、食物、药水、工具

打开与选择

  • 打开方式跟随菜单绑定：Press 为轻按打开（松手不关闭，再点确认或返回），Hold 为按住保持打开、松开关闭。
  • 选择摇杆：左摇杆、右摇杆或双摇杆（默认双摇杆）。
  • 菜单与层绑定：每个菜单有一个所属层。默认布局是：菜单 1 在 Main，菜单 2–5 分别在 Shift 1–4 —— 所以 Shift 层除了扩展按键，也是轮盘的入口层。

图标与外观

  • 图标模式：自动（按槽位内容推断，如物品图标）、随机、默认、物品 ID、或自定义纹理路径。
  • 游戏内编辑器可以调整图标、槽位顺序，以及每个菜单自己的触发方式。

0.9 新增：更多槽位、槽位状态、摇杆选择

  • 每个转盘的槽位上限从 8 提升到 12；内置菜单默认仍是 8 个。需要 Control Flex 0.9+。
  • use_item 槽位会显示物品的库存数量；缺失或未注册的物品以占位槽位保留，布局不会悄悄缩水。
  • 原版冷却以热键栏式的水位填充呈现，上方显示剩余秒数 —— 数量封顶 99+，超过 90 秒不再显示秒数。
  • 摇杆选择按扇区 + 10% 迟滞跟踪部分偏转，替代原来 0.5 的方形阈值，选择更顺滑、边界不抖动。
  • 转盘与槽位名称支持按语言各自命名。

配置文件

轮盘布局保存在 config/controlflex/radial_menu/radial_menus.json，图标资源放在同目录下。整合包可以把这个文件随包分发，让玩家开箱即用；文件结构（节选）： 

{
  "version": 1,
  "selectionStick": "BOTH",
  "menus": [
    { "id": 1, "name": "Menu 1", "mode": "HOLD",  "assignedLayer": "main",   "slots": [ 8 × slot ] },
    { "id": 2, "name": "Menu 2", "mode": "HOLD",  "assignedLayer": "shift1", "slots": [ … ] },
    { "id": 5, "name": "Menu 5", "mode": "PRESS", "assignedLayer": "shift4", "slots": [ … ] }
  ]
}

默认值（Basic 模板）

菜单 默认打开键
Main菜单 1Back（按住）
Shift 1菜单 2Back（按住）
Shift 2菜单 3Back（按住）
Shift 3菜单 4Back（按住）
Shift 4菜单 5Back（按住）

所有槽位出厂时都是空的 —— 轮盘是一个容器，内容由你（或整合包作者）填充。同一颗 Back 因为分属不同层，可以分别打开 5 个不同的轮盘。
