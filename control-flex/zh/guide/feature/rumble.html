功能详解

震动反馈

把 Minecraft 的事件翻译成手柄震动：7 种波形，按事件类型分别配置，再配一组轻 / 中 / 重的强度阈值 —— 挨打和击杀的手感可以完全不同。

7 种波形

波形 手感
关闭该类型不震动
脉冲短促的一下，适合轻伤害
双脉冲两连击的手感
渐强由弱渐强的推进感
长震持续震动，适合爆炸等大事件
渐弱由强渐弱，收尾感
心跳两下轻一重的节律，适合低血量 / 紧张场景

按事件类型配置

  • 伤害类型：摔落、火焰、溺水、生物、玩家、爆炸、其他 —— 每类单独选波形（含“关闭”）。
  • 击杀事件：击杀实体也可以有自己的反馈。
  • 强度分级：全局的轻 / 中 / 重伤害阈值，让同一种伤害按轻重给出不同强度。
  • 总开关：不想震的时候一键关闭全部反馈。

怎么调

  1. 打开 Control Flex 设置 → 震动，先确认当前手柄被识别为支持震动（不支持震动的手柄该页无效果）。
  2. 用页面上的强度档位测试逐档试听轻 / 中 / 重的手感，再决定阈值。
  3. 按事件类型挑波形：摔落之类的小事件用脉冲，爆炸用长震，被玩家击杀可以留给“玩家伤害”单独配置。

联机时自己的震动只受自己的设置影响；多人战斗里的反馈事件（打出伤害 / 被谁打）由游戏事件驱动，因此在服务器与单机中的表现一致。
