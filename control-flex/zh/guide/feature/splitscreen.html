功能详解

分屏双人（同机合作）

Java 版不在同一个窗口里渲染两名玩家，所以“同机双人”的形态是：同一台电脑上开两个客户端，通过“对局域网开放”联机，各自用自己的手柄。Control Flex 为这个用法做了两处专门支持：手柄归属与失焦窗口继续运行。

你需要准备

  • 两个以上的 Minecraft 账号 —— 离线账号也行，同一启动器里建两个不同的离线用户名就够了，不用再买一个正版账号。
  • 两把手柄，或者一把手柄 + 一套键鼠。
  • 一个能同时开两个实例的启动器（见下）。
  • 每一个“用手柄”的实例都安装 Control Flex。
  • 可选：Splitscreen Support（只做窗口平铺，不处理输入）。

支持多实例的启动器

关键是实例要真正隔离 —— 每个实例有自己的 mods/、config/ 和存档。下面这些启动器天生就是这种结构，两个客户端并排跑不会抢同一份文件。

启动器 说明
Prism Launcher Windows · macOS · Linux —— 开源的 MultiMC 分支，实例天然隔离：每个实例有自己的 mods/、config/、存档与 Java 版本；离线账户直接在账户页添加。
ATLauncher Windows · macOS · Linux —— 有独立的实例列表，每个实例一个目录，可从 CurseForge / Modrinth 导入整合包。
HMCL Windows · macOS · Linux —— 「版本隔离」把每个版本的游戏目录分开，支持离线登录。
PCL2 Windows —— 「版本隔离」把每个版本的游戏目录分开；启动第二个版本时会提醒一次，确认继续就能开第二个客户端。
X Minecraft Launcher Windows · macOS · Linux —— 以实例为单位管理，每个实例的模组与设置互相隔离，支持离线账户。
Modrinth App Windows · macOS —— 实例彼此隔离；Linux 支持仍属实验阶段。

离线账号有两点要注意：两个实例要用不同的用户名 —— 这个名字就是游戏内的玩家名，重名会在局域网里撞车；对局域网开放不验证正版，离线客户端可以直接加入，只有专门搭的服务器才需要在 server.properties 里把 online-mode 设为 false。

步骤

  1. 为每个账号各建一个启动器实例，两边都保持窗口模式（不要全屏）。
  2. 安装模组：手柄实例装 Control Flex（可选再装 Splitscreen Support）。
  3. 启动两个客户端。双柄场景：在两边的 手柄选择里分别指定不同的手柄；手柄 + 键鼠场景：只给那个手柄实例指定手柄，另一位用键鼠。
  4. 每个窗口按 F3+P 关闭“失去焦点时暂停”（或在视频设置里改）—— 后台窗口必须继续运行；暂停界面也会有提示。
  5. 装了 Splitscreen Support 的话，按 F11 循环半屏 / 四分之一屏布局，它会记住上次的位置。
  6. 在其中一个实例上对局域网开放，其他实例从多人游戏列表里加入，或用 localhost + 开放时的端口连接。

视角模式的选择

  • 后台窗口用 Direct Turn 或 Smooth Turn。
  • Simulate Mouse 无法驱动后台窗口的系统光标，会自动回退到 Direct Turn —— 想避开这种切换就统一用 Direct / Smooth。

手柄“抢输入”是多手柄场景最常见的问题：SDL3 会如实报告设备，但两个客户端各自选了同一把。只要在手柄选择里分配不同的设备即可；手柄断开时 Control Flex 会自动切到第一把可用手柄，所以尽量使用各自固定的那一把。
