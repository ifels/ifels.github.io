功能详解

模拟移动（360°）

原版 Minecraft 只把 WASD 当作开关，所以“摇杆转按键”只能八方向全速行走。开启模拟移动后，Control Flex 直接提供连续的 360° 移动向量：任意角度，轻推即慢走。

两种策略

策略 行为 适合
Analog Smooth 方向与推杆幅度原样使用 —— 主机式手感 单机、局域网、允许平滑移动的服务器
键盘式 8 向 摇杆吸附到八个方向、全速行走，在服务器看来与键盘输入一致 公共服务器与 Realms

默认怎么选

默认策略随连接场景自动变化：

  • 单机 / 局域网 → Analog Smooth
  • 公共服务器与 Realms → 键盘式 8 向，避免“摇杆幅度”被服务端反作弊视为异常输入

在哪里设置

  • Control Flex 设置 → 其他 → 模拟移动：总开关 + 策略选择。
  • 服务器白名单：确需在某个远程服务器使用 Analog Smooth 时，在同一页把它加入白名单（host:port 或 Realm 名称）。
  • 关闭总开关后回到数字 WASD 绑定；策略选项随之失效。

与校准的关系

移动手感的另外两个旋钮在校准页：摇杆死区（每根摇杆一个值，按手柄分别保存）与移动响应曲线。死区没调好时，轻推可能不动或漂移 —— 先跑一次自动校准，再微调死区，最后再调响应曲线。

在服务器上“看起来像键盘”只影响移动向量的形态，不影响你按下的任何动作键 —— 战斗、交互等绑定照常工作。

相关：视角控制（视角的响应曲线同样在校准页）、设置与键位（校准操作步骤）。
