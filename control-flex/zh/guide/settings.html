设置与键位

设置界面用 F9（键盘）或 Back + Start（手柄）打开。这一页讲清楚：界面里有什么、怎么改键、怎么校准、配置存在哪、出问题先看什么。

设置界面一览

区域 用途
按键映射 按层（Main / Shift 1–4 / Screen / Overlay）查看与修改全部绑定；支持搜索（含拼音搜索）与筛选
模组适配 按模组查看发现的按键，添加 Screen / Overlay 规则，同步社区配置 —— 详见模组兼容性
校准 摇杆死区与移动 / 视角响应曲线；自动或逐轴校准
其他设置 Tap / Long Press 阈值、模拟移动（360°）与服务器白名单等全局项
手柄选择 查看已识别的手柄（名称 / 类型 / 序列号），多手柄时指定当前使用哪一把

改键方法

  1. 在按键映射里找到目标动作所在的层与分类（可以用搜索框直接搜动作名或拼音）。
  2. 点选该行进入捕获状态，然后按下手柄按键 —— 界面会实时显示解析结果。
  3. 需要和弦时：先按第一颗键，在 500 ms 内继续追加，直到和弦完整。
  4. 部分动作有推荐模式（例如层切换固定为 Hold、Shift 层返回 Main 固定为 Release），界面会限制为可用模式。

被修改过的项会标记为“用户修改（User modified）”，与模板默认值区分开；可以按页重置，也可以整体恢复模板默认。

摇杆与扳机校准

  • 死区按轴独立配置：左摇杆 X/Y、右摇杆 X/Y、左扳机、右扳机。
  • 支持一键自动校准（全部轴）与单项校准（只针对某个轴），校准时实时显示轴数值，便于确认摇杆是否漂移。
  • 移动与视角的响应曲线也在这页调整；模拟移动策略（360° / 键盘式 8 向）在“其他设置”里。

模板、配置档案与重置

  • 模板（Basic / Bedrock / Recommend）是一套完整的默认键位；自定义模板可以作为 JSON 放入 config/controlflex/templates/。
  • 你的修改保存在配置档案（profiles）里，与模板分离 —— 切换模板不会丢失，也不会改写模板文件。
  • 支持按页重置和整体重置到模板默认。
  • 从 0.8.6.x 升级时，配置档案、兼容文件与客户端设置会在首次启动时自动迁移，原文件备份在 config/controlflex/backup/ 下。

按键检测（调试）

排查“为什么这个键没反应”时，可以打开逐 tick 的检测日志面板：它会显示物理按键、虚拟按键、解析出的动作、所在层与时间信息，并提供游戏内 / GUI 两种测试模式以匹配不同输入路径。面板激活期间，手柄输入专用于记录。

配置文件位置

config/controlflex/
├── templates/      # template JSON files
├── profiles/       # your edits (profiles)
├── compat/         # mod compat configs (default / mods / user)
├── radial_menu/    # radial menu layouts and icons
├── backup/         # automatic backups from migrations
└── cfx-client.json # client state

整合包作者关心的分层与覆盖规则在配置文件页。

常见问题

手柄完全没反应

先在“手柄选择”里确认是否识别到设备（名称 / 类型）。若列表为空：换一个 USB 口或重新配对蓝牙、确认系统里手柄可用、确认 JAR 与 MC 版本 / 加载器匹配；Fabric 环境请确认 Fabric API 已安装。

某个模组的按键绑了却没反应

按顺序检查：① 这个界面属于哪一层（Screen / Overlay / Main），绑到正确的层；② 在“模组适配”里为该模组的界面添加规则或同步社区配置；③ 若模组只监听物理键，用虚拟键鼠绑定。完整排查流程见模组兼容性。

服务器上移动看起来“不正常”

把模拟移动策略切换为“键盘式 8 向”（公共服务器与 Realms 的默认值）；确需平滑移动时把该服务器加入白名单。见模拟移动。

切到别的窗口后角色不动了

这是原版的“失去焦点时暂停”。按 F3+P 关闭（分屏双人必须关闭，暂停界面也会有提示）。

想彻底重来一遍

可以先把 config/controlflex/ 整个目录备份改名，再让游戏重新生成默认配置；社区配置与模组内的内置配置会在下次启动时重新释放。
