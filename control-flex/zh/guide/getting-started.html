快速上手

从下载安装到手柄跑起来，大约需要五分钟。

前置要求

组件 要求
Minecraft 1.7.10 – 26.3，共 13 个版本：1.20.1 / 1.19.2 / 1.18.2（Forge / Fabric）；1.21.1、1.21.11、26.x（NeoForge / Fabric）；1.16.5 及更早为 Forge 版（1.16.5 另有 Fabric 版）—— 详见 MC 版本支持
Java 8（1.16.5 及更早）；17（1.18.2 – 1.20.1）；21（1.21.x）；25（26.x）
Fabric API Fabric 版必需（Forge / NeoForge 版无需额外依赖）
SDL3 桌面三平台已内置，无需单独安装；Android 上由启动器提供 —— 详见 平台支持
运行平台 Windows（x86_64 / ARM64）、macOS（Intel / Apple Silicon）、Linux（x86_64 / aarch64）；Android 通过启动器运行（FCL / Zalith Launcher 2 / Mojo / Amethyst）—— 详见 平台支持
安装侧 仅客户端；服务器无需安装，也不会影响不装本模组的玩家
兼容手柄 Xbox One / Series X|S、PS4 / PS5（DualShock 4、DualSense）、Switch Pro、Xbox Elite（含背键）、Steam Controller、通用 XInput / DirectInput 手柄

下载与安装

  1. 在 CurseForge 项目页的 Files 中选择与你的 MC 版本、加载器一致的 JAR。
  2. 把 JAR 放入游戏的 mods/ 文件夹（Fabric 版请确认已安装 Fabric API）。
  3. 启动游戏。控制器的连接状态、名称与类型可在 Control Flex 设置 → 手柄选择（Gamepad Selection）中查看。

多手柄（热插拔）：Control Flex 通过 SDL3 热插拔事件自动识别手柄，按手柄身份（名称 / 类型 / 序列号）分别记忆配置；当前手柄断开后会自动切换到下一个可用手柄。

在 Android 上（Fold Craft Launcher、Zalith Launcher 2、Mojo、Amethyst 等启动器）：把 JAR 放进该实例的 mods/ 即可，不需要另外安装 SDL3 —— 它来自启动器本身。还有三处要留意：启动器的 -Dos.version 不能被自定义 JVM 参数覆盖，否则模组会把环境当成桌面 Linux，手柄始终不显示；把启动器自带的虚拟鼠标指针藏掉（关闭显示，或大小 / 不透明度设为 0）；ZL2 与 FCL 的手柄输入模式要选 SDL 直通。详见 平台支持。

打开设置

默认按键：键盘 F9，手柄 Back + Start。这个按键本身也是一个可改绑的动作，位置在按键映射的 Control Flex 分类里。

选择模板

首次启动会内置三个模板，可在设置中随时切换：

模板定位
Basic基础映射：A 跳跃、RT 攻击、LT 使用、左摇杆移动、右摇杆视角
Bedrock贴近基岩版手柄布局的手感
Recommend作者推荐的整合包向布局，预置更多常用动作

模板就是一套默认键位；你自己的修改会单独保存，不污染模板。详见设置与键位。

Overlay 层（交互式 HUD 打开时）

Overlay 层是显式绑定、不继承 Main：默认保留移动、跳跃、攻击、使用、视角与滚动，B 为返回。未配置的动作在 Overlay 相位中保持静默，避免误触发战斗键位。

虚拟键鼠与阈值

  • 虚拟键鼠：B 在界面中注入物理 Esc；LT 注入左 Shift（GUI 层）；Page Up / Page Down 已配置为 GUI 层可用。
  • 阈值默认值：Tap 500 ms，Long Press 1000 ms（可在“其他设置”中调整）。

以上是 Basic 模板的默认值。Bedrock 与 Recommend 模板略有差异，所有键位都可以在设置里改绑 —— 改键方法与校准请看设置与键位。
