ControlFlexApi

桥接模组的唯一入口。Control Flex 未安装或未初始化时，所有方法返回安全默认值。 The single entry point for bridge mods. Every method returns safe defaults when Control Flex is absent or not initialized. 

public final class ControlFlexApi

// Availability
boolean isAvailable()               // installed and fully initialized
boolean isControllerConnected()     // a controller is connected

// Providers (null = not available)
IActionStateProvider getActionStateProvider()
IInputProvider getInputProvider()
IPlayerStateRegistry getPlayerStateRegistry()
IInputInjector getInputInjector()
IInteractiveContextRegistrar getInteractiveContextRegistrar()

// Utilities
String getApiVersion()              // e.g. "0.8.9"
void reloadGuides()                 // reload guide configs

IControlFlexPlugin

桥接模组的 SPI 接口，通过 META-INF/services/ 注册。 The SPI interface for bridge mods, registered via META-INF/services/. 

String getModId()

// Lifecycle callbacks (in call order):
void onInstallCompatConfigs(ICompatAssetInstaller installer)   // export compat JSON
void onInstallGuideAssets(ICompatAssetInstaller installer)     // export guide JSON
void onControlFlexReady()                                       // Control Flex is ready
void onControllerConnectionChanged(boolean connected)           // controller plug/unplug

// Utility:

生命周期时序Lifecycle Timing

Control Flex startup
  └── initializeClient()
        → API providers injected (isAvailable() = true)
        → built-in configs extracted to default/

  └── onKeyMappingsReady()
        └── discover SPI plugins
              ├── new CompatAssetInstaller(plugin.class, compatDir)
              ├── plugin.onInstallCompatConfigs(installer)
              ├── new CompatAssetInstaller(plugin.class, guideDir)
              ├── plugin.onInstallGuideAssets(installer)
              └── plugin.onControlFlexReady()

  Runtime:
        └── plugin.onControllerConnectionChanged(connected)

ICompatAssetInstaller

资源安装器。Control Flex 创建实例并注入插件的 ClassLoader 与目标目录。 Asset installer. Control Flex creates the instance and injects the plugin's ClassLoader and target directory. 

boolean install(String resourcePath, String fileName)
// resourcePath: classpath path, e.g. "/assets/mymod/compat/epicfight_keys.json"
// fileName:      target filename in the mods/ config directory
// returns:       true if installed successfully
@Override
public void onInstallCompatConfigs(ICompatAssetInstaller installer) {
    installer.install("/assets/mymod/compat/epicfight_keys.json", "epicfight_keys.json");
}

@Override
public void onInstallGuideAssets(ICompatAssetInstaller installer) {
    installer.install("/assets/mymod/guides/epicfight_guid.json", "epicfight_guid.json");
}

IPlayerStateRegistry

桥接模组向 Control Flex 推送状态，供 compat JSON 中的 playerState 条件使用。 Bridge mods push states to Control Flex for use by playerState conditions in compat JSON. 

void setState(String stateKey, boolean active)  // thread-safe
boolean getState(String stateKey)               // client thread
void clearState(String stateKey)                // remove the registration

stateKey 格式："modId:stateName"，例如 "epicfight:battle_mode"。 stateKey format: "modId:stateName", e.g. "epicfight:battle_mode".

IInputInjector

虚拟手柄输入注入，供测试工具与桥接模组使用。注入状态是粘性的（按钮按下后保持，直到释放或清除），并与真实手柄输入一样走正常的按键绑定流水线。 Virtual controller input injection for test tools and bridge mods. Injected state is sticky (a pressed button stays pressed until released or cleared) and flows through the normal binding pipeline like real input. 

void pressButton(String buttonName, boolean pressed)  // ButtonName constants; stick directions map to axes
void setAxis(String axisName, float value)            // -1.0..1.0; 0 clears the override
void clearAll()                                       // release all buttons, zero all axes

线程安全：实现必须可跨线程调用；状态在客户端 tick 上原子应用。 Thread safety: implementations must be callable from any thread; state is applied atomically on the client tick.

IInteractiveContextRegistrar

声明交互式 Overlay：前台表示交互式 Overlay 打开，后台表示其关闭。Control Flex 据此将该类名记为当前活跃 Overlay，并在 OVERLAY 相位期间切换摇杆行为；场景退出时也会自动清除作为兜底。 Declare interactive overlays: foreground means the overlay is open, background means it closed. Control Flex records the class name as the active overlay, switches stick behavior during the OVERLAY phase, and clears it automatically when the scene unloads as a fallback. 

void notifyOverlayForeground(String className)   // overlay enters foreground
void notifyOverlayBackground(String className)   // returns to background (pairs with foreground)
void clearAll()                                   // fallback for mod unload / leaving the world

className 为交互式 Overlay 的全限定类名 —— 该类名的摇杆行为由 Control Flex 的 compat 配置解析。仅限客户端线程；getInteractiveContextRegistrar() 可能为 null，调用前需判空。 className is the fully qualified class name of the interactive overlay — its stick behavior is resolved by Control Flex's compat configs. Client thread only; getInteractiveContextRegistrar() may be null, so null-check before calling.

0.8.7 破坏性变更：这两个方法由 0.8.6 的 notifyForeground / notifyBackground 改名而来；按 0.8.6 名称编译的模组需要针对新版本重新编译。 0.8.7 breaking change: these methods were renamed from notifyForeground / notifyBackground in 0.8.6; mods compiled against the old names must be recompiled.
