Features

Screen Menu

A Screen Menu is a bindable, radial-style list of actions that opens on top of any screen Control Flex knows about — inventories, quest books, mod GUIs — without closing the screen underneath. Open it with a button, pick an entry, and the action fires as if you had navigated there yourself. Requires Control Flex 0.9+.

How It Works

  • Five menus, five bindings: screen_menu_open_1 – screen_menu_open_5 are regular rebindable actions, bound out of the box.
  • Drawn over the screen: the menu renders as a radial-style panel on top of whatever screen is open; while it is up, a modal input mask keeps clicks and keys away from the screen underneath.
  • Slots come from compat + config: a mod's compat entry (or your own config) can prefill a menu with actions; unusable slots are filtered out at load.
  • One action per slot: hand-edited JSON gets the same validation as the in-game editor.

Editing in Settings

  • The per-screen settings page gains a Menu tab: menu list, an editor with drag reorder, name / position / height / scale, and a live preview.
  • A duplicate click answers with a toast instead of silently dropping the slot later.
  • Layer Mapping gains Hide inactive actions: the table lists only the rows that can fire on this screen; Reset still walks the unfiltered set.
