Features

Split-Screen Co-op

Java Edition does not render two players in one window, so couch co-op means two clients on one PC joined over Open to LAN, each with its own controller. Control Flex supports that setup in two specific ways: controller ownership and unfocused windows that keep playing.

What You Need

  • Two or more Minecraft accounts.
  • Two gamepads, or one gamepad plus keyboard and mouse.
  • A launcher that can run two instances at once.
  • Control Flex installed in each instance that uses a gamepad.
  • Optional: Splitscreen Support (window tiling only, no input handling).

Steps

  1. Create one launcher instance per account; keep both windowed (not fullscreen).
  2. Install the mods: Control Flex in the gamepad instances, optionally Splitscreen Support too.
  3. Launch both. Two pads: pick a different controller in each game's Gamepad Selection. Pad + keyboard: assign the pad in the gamepad instance only.
  4. Press F3+P in each window to disable Pause on Lost Focus (or change it in video options) — the unfocused window must keep running; the pause screen also shows a hint.
  5. With Splitscreen Support, press F11 to cycle half- and quarter-screen layouts; the last position is remembered.
  6. Host on one instance (Open to LAN); join from the others from the multiplayer list, or via localhost plus the port shown.

Picking a Look Mode

  • Use Direct Turn or Smooth Turn in background windows.
  • Simulate Mouse cannot drive the OS cursor in a background window and falls back to Direct Turn automatically — use Direct or Smooth everywhere to avoid the switch.

“Input stealing” is the classic two-pad problem: SDL3 reports devices honestly, but both clients might pick the same one. Just assign different devices in Gamepad Selection. When a pad disconnects, Control Flex auto-selects the first available one, so keep each player on their own device.
