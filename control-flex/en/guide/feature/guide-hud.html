Features

In-Game Guide

No need to alt-tab to a document: Control Flex brings the reference into the game. Context HUD tips appear for the current action, held item, open screen, or controller button, and the guide list gathers everything available.

Context HUD Tips

Guide entries can be marked for HUD display: those tips appear on screen in context — the movement and interaction basics when you first join, tips for a specific held item, or the key hints for a screen you just opened. Entries reference Control Flex actions directly, so your own rebinds are reflected in the tips.

The Guide List

  • Press the Guide button to open the list (open_guide, bound to Guide in the Basic template); LB / RB switch tabs inside.
  • The list is organized by category; each guide has a trigger (such as “first join”) plus entries made of an action, a label, and a display mode.

Button Glyphs Follow the Platform

Glyphs in the tips follow the connected controller: Xbox, PlayStation, and Switch layouts each have their own mappings, and the Nintendo layout handles the A/B swap — so the same tip shows the right icons on a DualSense and an Xbox pad alike.

Config Files

Guide JSON lives in config/controlflex/guides/ (layered: default/ packaged, mods/ installed by bridge mods, user/ your edits); the packaged defaults are copied out on first run. Structure (excerpt): 

{
  "mod_id": "controlflex",
  "categories": [
    {
      "id": "basic",
      "guides": [
        {
          "id": "movement",
          "title": "controlflex.guide.basic.movement",
          "trigger": { "type": "first_join" },
          "entries": [
            { "action": "move_forward", "label": "controlflex.guide.entry.move", "display": "auto_move", "hud": true },
            { "action": "jump",         "label": "controlflex.guide.entry.jump",  "hud": true }
          ]
        }
      ]
    }
  ]
}

When It Helps

  • Pack authors: ship a guide describing your pack's controller layout so new players see it the moment they join.
  • Bridge mods: install guide assets alongside compat configs (onInstallGuideAssets, see Integration & lifecycle) to add tips for key actions.

Related: Settings & Controls (the key-detection panel for debugging missing tips) and the API Reference (reloadGuides() and IControllerCapabilities).
