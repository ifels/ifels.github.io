Features

Analog Movement (360°)

Vanilla Minecraft only sees WASD as on/off, so stick-to-keys walking is limited to eight directions at full speed. With Analog Movement, Control Flex feeds a continuous 360° vector: any angle, and a light push walks slowly.

Two Policies

Policy Behavior Best for
Analog Smooth Direction and magnitude used as-is — the console feel Singleplayer, LAN, and servers that tolerate smooth movement
Keyboard-like 8-way Stick snapped to eight directions at full speed, which looks like keyboard input to a server Public servers and Realms

How the Default Is Chosen

The default follows the connection:

  • Singleplayer / LAN → Analog Smooth
  • Public servers and Realms → keyboard-like 8-way, so analog walk is less likely to look like abnormal input to server-side anti-cheat

Where to Configure

  • Control Flex Settings → Other → Analog Movement: master switch plus policy.
  • Server whitelist: if a specific remote server should still get Analog Smooth, add it (host:port or Realm name) on the same page.
  • Turning the master switch off restores digital WASD bindings; the policy then does nothing.

Relation to Calibration

Two more knobs live on the Calibration page: stick deadzones (one value per stick, saved per controller) and the movement response curve. If a light push does nothing or drifts, run auto calibration first, then fine-tune the deadzone, and only then adjust the response curve.

Looking keyboard-like on a server only changes the shape of the movement vector; every action key you press behaves exactly the same.

Related: Camera Look (the look curve also lives under Calibration) and Settings & Controls (calibration steps).
