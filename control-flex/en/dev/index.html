API Quick Start

The Control Flex API (currently 0.8.9) is for bridge mod developers: read controller input, query action states, push mod states, and export compat configs. Repository: ControlFlexMC/control-flex-api.

1. Project Setup

// build.gradle
repositories {
    maven { url 'https://jitpack.io' }
}

dependencies {
    // compileOnly — provided by the Control Flex mod at runtime
    compileOnly 'com.github.ControlFlexMC:control-flex-api:0.8.9'
    compileOnly 'org.jetbrains:annotations:24.0.1'
}

Declare the Control Flex dependency so the loader orders things correctly: 

# mods.toml (Forge / NeoForge)
[[dependencies.your_mod_id]]
    modId = "controlflex"
    mandatory = true
    versionRange = "[0.8.7,)"
    ordering = "AFTER"
    side = "CLIENT"
// fabric.mod.json (Fabric)
{
  "depends": {
    "controlflex": ">=0.8.7"
  }
}

The API is published as Java 8 bytecode, so bridge mods on a range of toolchains can consume it.

2. Always Check Availability First

Control Flex may not be installed, or SDL3 may fail to initialize. So the first check is always: 

if (!ControlFlexApi.isAvailable()) {
    // fall back: skip all controller-related handling
    return;
}

3. API Overview

ControlFlexApi (static entry point)
├── getActionStateProvider()            → IActionStateProvider          query action states
├── getInputProvider()                  → IInputProvider                read controller input
│                                          ├── getControllerState()    → IControllerState
│                                          └── getCapabilities()       → IControllerCapabilities
├── getPlayerStateRegistry()            → IPlayerStateRegistry          push mod states
├── getInputInjector()                  → IInputInjector                inject virtual input
├── getInteractiveContextRegistrar()    → IInteractiveContextRegistrar overlay foreground/background
└── isAvailable() / isControllerConnected() / getApiVersion() / reloadGuides()

4. Two Ways to Adapt a Mod

Compat JSON Bridge Mod (Java)
How Write a JSON config file Implement IControlFlexPlugin (SPI)
Power Key classification, event control, conditional suppression Fully custom: input reading, state sync
Use when The mod's keys are registered via MC KeyMapping The mod has its own input system or runtime state
Examples JEI · Nightfall Epic Fight (cfx-compat-epicfight)

For the full compat JSON field set, see Mod Compatibility and the cfx-compat-configs field reference.

5. Your First Bridge Mod

package com.example.mymod;

import com.ifels.controlflex.api.*;

public class MyPlugin implements IControlFlexPlugin {

    @Override
    public String getModId() {
        return "my_bridge_mod";
    }

    @Override
    public void onControlFlexReady() {
        if (!requireApiVersion("0.8.7")) return;
        if (!ControlFlexApi.isAvailable()) return;

        IPlayerStateRegistry states = ControlFlexApi.getPlayerStateRegistry();
        states.setState("mymod:initialized", true);
    }
}

Register it through the SPI services file — Control Flex discovers plugins automatically: 

src/main/resources/META-INF/services/com.ifels.controlflex.api.IControlFlexPlugin

com.example.mymod.MyPlugin
