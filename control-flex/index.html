Control Flex

面向整合包的灵活手柄映射模组 —— 把一个手柄，变成整包的操作台。 Flexible controller mapping for Minecraft Java Edition, built for modpacks.

Minecraft 1.20.1 – 26.3 NeoForge / Fabric 仅客户端Client-side MIT
前往下载（CurseForge）Download on CurseForge GitHub Discord

Control Flex 的名字取自 Control + Flex：通过 7 层按键架构、10 种触发模式、组合键、径向菜单和跨层映射，把有限的按键变成对模组内容的广泛覆盖。它的模组适配系统可以自动发现模组按键、按界面（Screen / Overlay）定制摇杆行为，并支持社区配置库与桥接模组 API。

Control Flex turns a limited set of buttons into broad coverage of modded content through a seven-layer binding architecture, ten trigger modes, combo keys, radial menus, and cross-layer mappings. Its mod adaptation system auto-discovers mod keys, adapts stick behavior per screen or overlay, and supports a community config repo plus a bridge-mod API.

功能亮点Feature Highlights

7 层按键架构7-Layer Bindings

Main / Shift 1–4 / Screen / Overlay，每个场景各自一套键位，空槽自动继承 Main。Main / Shift 1–4 / Screen / Overlay — one map per context, with Main inheritance.

10 种触发模式10 Trigger Modes

Press、Release、Hold、Tap、Long Press、Toggle 及四种双击变体，一个按键多种行为。Press, Release, Hold, Tap, Long Press, Toggle, plus four double-tap variants.

组合键Combo Keys

多键和弦触发一个动作，带优先级升级规则，适合把低频动作收进和弦。Chord multiple buttons into one action, with priority-based upgrade rules.

径向菜单Radial Menus

5 个轮盘 × 8 个槽位，可绑定按键、命令或快捷使用物品。5 wheels × 8 slots for keys, commands, or use-item actions.

模组适配Mod Adaptation

自动发现模组按键，按界面配置摇杆行为；社区配置库一键同步。Auto-discovers mod keys with per-screen stick rules and a community config repo.

模拟移动与震动Analog Move & Rumble

360° 摇杆移动（服务器可切换键盘式 8 向）；按伤害类型配置震动反馈。360° analog movement (keyboard-like 8-way on servers) and per-damage-type rumble.

三步上手Up and Running in Three Steps

  1. 在 CurseForge 下载对应 MC 版本与加载器的 JAR，放进 mods/ 文件夹。Download the JAR for your MC version and loader from CurseForge and drop it into mods/.
  2. 启动游戏，连接手柄 —— Control Flex 通过 SDL3 自动识别（支持热插拔）。Launch the game and connect a controller — Control Flex detects it via SDL3 (hotplug supported).
  3. 按 F9（键盘）或 Back + Start（手柄）打开设置，选择模板并开始调整。Press F9 (keyboard) or Back + Start (controller) to open settings, pick a template, and start tuning.
