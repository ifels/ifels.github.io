Features

Radial Menus

Up to five independent wheels, each with as many as eight slots around the stick: open a wheel, aim with the stick, confirm with A. Food, torches, /home — frequent actions that do not deserve a dedicated face button belong on a wheel.

What a Slot Can Do

Type Effect Examples
Key binding Fires a vanilla or mod KeyMapping Perspective toggle, mod skill keys
Chat command Runs a / command /home · /spawn · /warp
Use item Switches to the hotbar slot and uses it Torches, food, potions, tools

Opening & Selecting

  • Opening follows the menu's binding: Press taps to open (release does not close it), Hold keeps it open while held and closes on release.
  • Selection stick: left, right, or both (both by default).
  • Menus are assigned to layers: by default Menu 1 lives on Main and Menus 2–5 on Shift 1–4 — Shift layers serve as wheel entry points as well as binding planes.

Icons & Appearance

  • Icon modes: auto (inferred from the slot's content, e.g. item icons), random, default, item ID, or a custom texture path.
  • The in-game editor lets you pick icons, reorder slots, and set the trigger mode per menu.

Config Files

Wheel layouts persist in config/controlflex/radial_menu/radial_menus.json with icons alongside. Packs can ship this file so players start with working wheels. Structure (excerpt): 

{
  "version": 1,
  "selectionStick": "BOTH",
  "menus": [
    { "id": 1, "name": "Menu 1", "mode": "HOLD",  "assignedLayer": "main",   "slots": [ 8 × slot ] },
    { "id": 2, "name": "Menu 2", "mode": "HOLD",  "assignedLayer": "shift1", "slots": [ … ] },
    { "id": 5, "name": "Menu 5", "mode": "PRESS", "assignedLayer": "shift4", "slots": [ … ] }
  ]
}

Defaults (Basic Template)

Menu Default open binding
MainMenu 1Back（按住）
Shift 1Menu 2Back（按住）
Shift 2Menu 3Back（按住）
Shift 3Menu 4Back（按住）
Shift 4Menu 5Back（按住）

All slots ship empty — a wheel is a container you (or a pack author) fill. The same Back button opens five different wheels because each menu belongs to a different layer.
