Control Flex

Flexible controller mapping for Minecraft Java Edition, built for modpacks.

Minecraft 1.7.10 – 26.3 Forge / NeoForge / Fabric Windows · macOS · Linux · Android
CurseForge GitHub Discord Kook

Control Flex turns a limited set of buttons into broad coverage of modded content through a seven-layer binding architecture, ten trigger modes, combo keys, radial menus, and cross-layer mappings. Its mod adaptation system auto-discovers mod keys, adapts stick behavior per screen or overlay, and supports a community config repo plus a bridge-mod API.

Up and Running in Three Steps

  1. Download the JAR for your MC version and loader from CurseForge and drop it into mods/.
  2. Launch the game and connect a controller — Control Flex detects it via SDL3 (hotplug supported).
  3. Press F9 (keyboard) or Back + Start (controller) to open settings, pick a template, and start tuning.
